# Pneumonia Detection using Deep Learning

## Project Overview

This project is an AI-powered web application developed for detecting pneumonia from chest X-ray images using Deep Learning techniques.

The system analyzes uploaded X-ray images and predicts whether the patient has Pneumonia or Normal condition.

---

## Features

✔ Upload chest X-ray image

✔ AI-based pneumonia prediction

✔ User-friendly web interface

✔ Fast prediction results

✔ Medical assistance information using database integration

---

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/Pneumonia_detection_project.git
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

---

## How It Works

1. User uploads chest X-ray image.
2. Image preprocessing is performed.
3. Deep learning model analyzes the image.
4. System predicts:
   - Pneumonia
   - Normal
5. Result is displayed through web interface.
